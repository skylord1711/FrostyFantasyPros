# Frosty Fantasy Pros (Client — PWA)

Mobile-first, installable React PWA. Talks to the Node server on :4700 via /api
(dev: Vite proxies /api to localhost:4700).

Run:  npm install && npm run dev   (http://localhost:5173)
Build: npm run build  -> dist/ (PWA: manifest, service worker, icons)

Features: connect/multi-league, dashboard, rankings, trade finder, WDIS,
waivers, matchups, power rankings, AI chat.
